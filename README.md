# Resume Studio · 简历工作台

纯前端、无需账号，附一份虚构模板，不含作者的个人简历。简历只保存在使用者的浏览器里，不上传服务器。

## 保存与隐私
正常关闭浏览器或关机后，用同一个浏览器配置打开相同网址，已保存的内容仍在。不同电脑、浏览器配置互不相通；共用同一个浏览器配置的人可以看到同一份本地简历。无痕模式、清理网站数据、浏览器回收存储、换设备可能导致数据丢失，请定期导出 JSON 备份。网站更新不主动清除原数据。

## 批量导入
点击左侧＋，按 Ctrl / Shift 多选 JSON 或 PDF。每个文件导入为新副本，不覆盖旧简历。坏文件单独报错，其他文件继续导入；右侧显示详细结果。JSON 支持单份简历或简历数组。单文件上限 30 MB。

PDF 在浏览器本机识别，不发送给 AI 或服务器。支持文字版 PDF，多页文件每页生成一份可编辑简历，最多 20 页。按文字行和位置生成字段，并非完整还原 Figma 分组：字体、颜色、加粗、图片和分隔线可能与原稿不同，请检查后使用。扫描件、图片和转曲文字暂不支持 OCR；加密文件需先解锁。

PDF 识别需通过 GitHub Pages 或本地网页服务打开。直接双击 index.html 时，原有编辑与 JSON 功能仍可使用，PDF 识别不可用。

## AI 修改
保持 JSON 方式：导出 JSON，与岗位要求一起交给用户自己的 AI，要求只修改 text/name、保留编号和排版参数。将 AI 返回的 JSON 导入为副本。只发网站链接不能让聊天网页操作浏览器中的私人简历。本版不使用 API Key，也不收取 API 费用。

## PDF 导出
浏览器打印选择另存为 PDF、A4、100%、关闭页眉页脚。使用系统字体，不同设备可能有字形差异。

## 更新 GitHub Pages
将 index.html、pdf-import.mjs、sample.json、README.md、.nojekyll 和整个 vendor 文件夹上传到仓库根目录，保留子目录结构。不要上传 ZIP 文件本身。若网页上传提示超过 100 个文件，可使用附带的三个分批上传包：逐个解压，每次拖入解压后的全部文件和 vendor 文件夹，分三次提交。三个包共同组成完整版本，缺少任何一包可能影响部分 PDF 识别。

Pages 设置：Deploy from a branch → main → / (root)。部署完成后刷新网站；已有浏览器简历保留。不要上传私人 resume_workbench 目录。

## 开源组件
PDF.js 6.5.438（Mozilla），许可证及字体等资源许可随 vendor/pdfjs 分发。所有依赖随网站提供，不从第三方 CDN 加载，不上传简历内容。
